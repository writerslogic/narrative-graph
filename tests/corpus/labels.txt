# HOW TO LABEL
# Each item is one sentence from a novel. The line starting with `~` is the
# sentence before it, there only to tell you who a pronoun means; do not label
# it. Under the `=` line, write one line per relationship the sentence itself
# states, or leave it empty if it states none:
#
#     Elizabeth | sister_of | Jane
#     not Wickham | husband_of | Lydia      (the sentence denies it)
#
# Rules:
# - `A | x_of | B` means "A is B's x". "Lydia's aunt" is `aunt | aunt_of | Lydia`
#   only if the aunt is named, e.g. `Mrs. Philips | aunt_of | Lydia`.
# - Both sides must be a named person (or place, for works_at), or a pronoun
#   whose person is named in this sentence or the `~` line. Write the name
#   as the text writes it there ("Mr. Darcy", "Darcy", "Lizzy"). Skip a side
#   that is only a description ("her mother", "the old man").
# - Label what the sentence states as true, including inside dialogue. Skip
#   what is only wished, asked, supposed, or conditional ("if she were his
#   sister").
# - Use the relation names below when one fits. If none fits, make one up in
#   the same style (`fiancee_of`, `ward_of`); it is scored separately as a
#   relation the library does not know yet.
# - Mutual relations (friend_of, cousin_of, spouse_of, knows, meets ...) only
#   need one direction. Kin terms with a sex (sister_of, son_of) do not.
# - Do not run the library on these sentences before labelling, and do not
#   edit the `@`, `~` or sentence lines: the test checks them against the book.
# - When unsure, write your best guess and add `?` at the end of the line;
#   those count like any other label but are easy to find later.
#
# Relations the library knows. Label the verb ones too ("Darcy met
# Bingley" is `Darcy | meets | Bingley`), including one-off events such as
# kissed or killed; the place ones take a named place as the object.
#
# People to people ("A is B's x"):
#   acquaintance_of ally_of apprentice_of assistant_of aunt_of boss_of
#   boyfriend_of brother_in_law_of brother_of classmate_of client_of
#   colleague_of companion_of cousin_of coworker_of daughter_of doctor_of
#   employer_of enemy_of ex_husband_of ex_of ex_wife_of father_in_law_of
#   father_of fiance_of friend_of girlfriend_of goddaughter_of godfather_of
#   godmother_of godson_of granddaughter_of grandfather_of grandmother_of
#   grandson_of guardian_of husband_of landlord_of lawyer_of lover_of
#   master_of mother_in_law_of mother_of neighbor_of nephew_of niece_of
#   partner_of patient_of pupil_of rival_of roommate_of servant_of sibling_of
#   sister_in_law_of sister_of son_of sponsor_of spouse_of stepbrother_of
#   stepdaughter_of stepfather_of stepmother_of stepsister_of stepson_of
#   student_of teacher_of tenant_of therapist_of twin_of uncle_of widow_of
#   wife_of
#
# Verbs ("A x B"), written exactly as listed whatever the text's tense:
#   adopted argues_with attends betrayed born_in broke_up_with comforts
